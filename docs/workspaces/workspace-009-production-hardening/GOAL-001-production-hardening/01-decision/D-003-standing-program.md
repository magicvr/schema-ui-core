# D-003 · 纠正为长期安全程序容器

## 决策

用户于 2026-08-10 书面指示：

> 直接修正 VP-009 和其对应的根目标的描述来作为长期意图与工作区；本身应承载持续安全扫描与加固语义。此前有界关门语义，是当时仅有一波待修 bug 导致的理解偏差。

据此：

1. **VP-009** 修订为**持续安全与健壮性程序**（`status: active`）；单波完成 / `go` 恢复 **不等于** VP 关门；退出仅限程序废弃、被 supersede 或用户有界关闭。
2. **Root GOAL-001** 保持 / 恢复 **`active`**，成功标准改为**程序能力 + 波次档案**；删除「S0–S2 全勾选 → Root done」的误用。
3. **已完成子目标** GOAL-002（W1）、GOAL-003（W2）**保持 `done`**，作为波次档案，不重开。
4. 历史「Root/VP closed」记录保留在修订史与 VP 误关门撤销说明中，**不作为现行状态**。
