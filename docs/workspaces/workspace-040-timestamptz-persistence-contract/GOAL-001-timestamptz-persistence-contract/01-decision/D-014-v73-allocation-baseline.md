# D-014 · v73–v87 allocation baseline 裁决

用户接受 proposed v73–v87 module allocation 作为 R2 当前 baseline：按模块 owner 一模块一个 conversion descriptor 起步；若真实 SQLite rebuild/PG constraint 需要拆分，可在 R2 实施前有记录地调整/消费连续追加版本；一旦 migration 进入已发布 history，严格 append-only，不重写既有版本/checksum。
