# D-001 · 信息裁决：I-028-001 / I-028-002 / I-028-003（2026-09-01 用户裁决）

## 上下文

R1 契约冻结前置三条 required 信息项（P-005 / P-004）。编排器基于仓库事实提出带建议的选项（端口先例 `kernel.Cache` / `RateLimiter` 非泛型、VP-021 停机合同、V-F103/V-F104），2026-09-01 经用户裁决。**未全部采纳建议项**：I-028-001 / I-028-002 用户选择了更强约束项；I-028-003 采纳建议项。

## 裁决记录

| ID | 级别 | 选项（用户所见） | 裁决 |
|----|------|------------------|------|
| I-028-001 | required | ① 接口断言 + 允许非序列化负载（建议） ② 注册表 topic→type + 可序列化约束 ③ 泛型端口 EventBus[T] | **采纳②**：topic→type 注册表；Publish 类型必须匹配已注册类型；负载必须 JSON 可序列化（fail-closed）。I-028-004 升为 required（最晚仍 R3）。理由：为 outbox/RT-Q06 预留可序列化约束，R1 显式记录未选方案（V-F103）。 |
| I-028-002 | required | ① 同步投递（建议） ② 异步 + 缓冲满阻塞 ③ 异步 + 缓冲满丢弃 ④ 异步 + 缓冲满返回错误 | **采纳②**：异步 channel 投递（Publish 不等待 handler 完成）；每订阅独立有界缓冲；缓冲满时发布者阻塞；须声明 SIGTERM 取消订阅/排空（V-F104 / 继承 VP-021）。 |
| I-028-003 | required | ① 吞掉+日志 + panic 隔离（建议） ② handler 错误回传发布者 ③ 仅 panic 隔离、error 仍回传 | **采纳①**：handler 无 error 通道（吞掉为结构）；供应商必须 recover panic 并记日志；多订阅独立失败；重复发布与多订阅均合法。 |

## 未选方案

| 项 | 未选 | 理由 |
|----|------|------|
| 接口断言、无注册表 | ① | 用户选择为 outbox 预留类型注册与可序列化约束 |
| 进程内允许非序列化负载 | ① 的负载半边 | 与 outbox/RT-Q06 接缝声明不对齐；用户明确要可序列化约束 |
| 泛型端口 `EventBus[T]` | ③ | 与仓库全部内核端口非泛型先例不一致 |
| 同步投递 | ① | 用户选择异步；因此 Stop 排空义务生效（不能再靠「无后台」躲开 VP-021） |
| 缓冲满丢弃 / 返回错误 | ③ / ④ | 用户冻结最小背压语义 = **阻塞**；完整背压产品仍 gated |
| handler 错误回传发布者 | ② / ③ | 发布者与消费方耦合，违背运输端口解耦 |

## 影响

- 合同正文 D-002 按本裁决冻结（§1 端口形状 / §2 注册表与序列化 / §3 异步投递与缓冲 / §4 错误语义 / §5 停机）。
- Root / VP-028 信息台账 I-028-001/002/003 → `verified`；I-028-004 升 required（R3）。
