## Findings

### F-S-002 · package finalization 与真实 tarball 消费未被合并门禁覆盖

- **级别 / 建议**：high / required（已 fixed）
- **状态**：closed · `fixed`
- **发现**：PR #16 合并后构建时未运行已有 `finalize-lib-dist.mjs`，protocol schema 文件没有进入 npm tarball；新的发布版本也暴露静态 JSON attributes、包子路径扩展名与 renderer alias 问题。仅看 build 成功、package-name 单测或 Hosted CI 不能证明 npm 包可消费。
- **闭合证据**：alias rewrite 现在在末尾自动运行 finalizer；compatibility normalizer 与测试覆盖 JSON attributes、公开包名和扩展名；新增 CI 实际打包 tarball 并在临时消费者中导入六包入口与代表子路径；本地 13 项 smoke 全通过。

## 结论

本地修复候选对已发现的 ESM 与资源缺失故障提供可复核修正，F-S-002 按 `fixed` 闭合。本意见不把 PR CI、npm 修复版发布、tag 或 Release 记成已完成；这些门禁须在后续产生独立证据。
