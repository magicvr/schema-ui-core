# E-003 · S3 P1：T-03 个人中心 Tabs + T-02 列表搜索矩阵

## 事实

### T-03 · 个人中心三档 Tabs（D-004）

1. `apps/api/internal/modules/account/schema/account.json`：body 由纵向平铺改为 `tabs` 节点，三档 —— 资料（profile form）｜安全（改密 + mfa-manager）｜会话（sessions table）。tab 子节点为带 `props.labelKey` 的 section。
2. `apps/web/src/renderer/render.tsx` `TabsView`：tab 标签解析 `labelKey`（`resolveTextProp` 优先 key，回退 `label`），与其它节点 i18n 约定一致。
3. i18n：`schema.account.tab.profile/security/sessions`（en/zh）。
4. 无新协议、无新路由；D-VAL 结构回归对 account.json 通过。

### T-02 · 列表搜索矩阵（D-003）

5. `apps/web/src/renderer/render.tsx` `searchFormSubmit` 泛化：除 `q` 外的全部表单字段绑定到目标表查询 `filters`（`buildResourceQuery` 序列化为 URL 参数）；本表单拥有的字段先清除再写入（清空 select 即移除参数，与 q 重置同纪律 C6）；表级 `props.filters` 选择器保留（非本表单所有）。
6. 12 页 schema 搜索表单按冻结矩阵改造（11 页改造 + notifications 新增 search form）：
   - users：q 改「用户名 / 显示名 / ID」+ `enabled` / `locked` select
   - roles：q 改「角色名 / Key」+ `system` select
   - activity：q 改「事件 / 操作者 / 资源」（仅关键词）
   - wallet：q 改「账户 / 所有者」+ `ownerType` select（API 已有）
   - wallet-entries：q 改「备注 / 关联单」；**entryType 降级为仅关键词**（list 无 entryType 谓词，D-003 降级规则）
   - file-library：q 改「文件名」
   - data-dictionary：q 改「字典 Key / 名称」
   - dictionary-entries：q 改「条目 Key / 名称」（dictKey 走既有路由绑定）
   - recycle-bin：q 改「资源 ID / 操作者」+ `resource` select（API 已有；选项 = 当前 Trash 注册资源 dict-types/dict-entries/scheduled-tasks）
   - scheduled-tasks：q 改「任务 Key / 名称」+ `enabled` select
   - task-runs：q 改「任务 Key」+ `status` select（ran/failed）
   - notifications：新增 search form（q「标题 / 正文」+ `read` select：全部/未读/已读）
7. 后端筛选接线（ExtraQuery 管道，GOAL-015 既有机制）：
   - users：`ExtraQuery ["enabled","locked"]`；`UserFilter.Enabled/Locked *bool`；`usersWhere` 支持（locked = `locked_until > now`）
   - roles：`ExtraQuery ["system"]`；`RoleFilter.System *bool`；`rolesWhere` 支持
   - scheduled-tasks：`ExtraQuery ["enabled"]`；`ListFilter.Enabled *bool`；`ListTasks` where 支持
   - task-runs：`ExtraQuery ["status"]`；`ListFilter.Status string`；`ListAllRuns` where 支持
   - notifications：handler 读 `q` + `read`（unread|read）；`NotificationFilter.Q/Read *bool`；list SQL 支持 title/body 关键词与 read_at 谓词
   - wallet / recycle-bin：既有 query 参数，仅 schema 接线
8. i18n：新增 12 页搜索/筛选标签与选项键（en/zh 各 ~50 键）。
9. 新测试 `apps/web/src/renderer/search-form-filters.test.tsx`：select 筛选经搜索表单提交后进入请求 URL（`q=ali&enabled=true`）。
