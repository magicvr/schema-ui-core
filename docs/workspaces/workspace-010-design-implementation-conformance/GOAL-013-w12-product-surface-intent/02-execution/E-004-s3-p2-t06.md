# E-004 · S3 P2：T-06 模块启用只认 config.yaml

## 事实

### 配置加载（D-007 / D-008）

1. `apps/api/internal/config/config.go`：
   - `yamlFile.App` 移除 `modules_enabled`（逗号串）与 env 读取；新增 `Modules yaml.Node`。
   - 移除 `APP_PROFILE` / `APP_MODULES_ENABLED` 环境变量覆盖（`cfg.ProfileName = envOr("APP_PROFILE", ...)` 与 `os.Getenv("APP_MODULES_ENABLED")` 整段删除）。
   - 新增 `resolveModulesFromYAML`：`app.modules` 三形态 —— `preset: mvp|admin|demo`（内置编译预设）、`preset: <path>`（自定义预设文件，`modules:` 列表）、`list: [...]`（内联，custom 形态）；preset 与 list 互斥（fail closed）；缺省回退 `app.profile` 内置默认。Source 分别为 `modules.preset` / `modules.list` / `profile.default`。
   - 新增 `loadPresetFile`：KnownFields 严格解析自定义预设文件，空文件/空列表 fail closed。
2. `apps/api/internal/kernel/profile.go`：custom 缺模块错误信息改为提示 `app.modules`；Precedence 由 `{compiled-profile-default, modules.enabled, environment}` 改为 `{compiled-profile-default, modules.preset, modules.list}`；显式模块 Source 改为 `modules.list`。
3. 保留 W7 密钥插值：${VAR} / ${VAR:-default}、CONFIG_FILE、configs/.env 机制不变（I-006 裁决：只取消模块启用 env）。

### 教学面 / 部署契约

4. `config.default.yaml` / `configs/config.yaml`：`modules_enabled` 替换为 `app.modules` 文档与示例（preset / list 注释）。
5. `compose.yaml`：移除 `APP_PROFILE` / `APP_MODULES_ENABLED` 环境变量；新增 `./apps/api/configs:/app/configs:ro` 挂载（operator 配置文件进容器）；注释更新为「编辑 configs/config.yaml 的 app.modules 选模块」。
6. `dev.cmd`：启动 API 前向 `%TEMP%` 写 overlay 配置（`app.env/profile/modules + http.addr`）并设置 `CONFIG_FILE`；`--profile` / `--modules` 语义保持（写进 YAML 而非 env）。
7. 文档：README.md / QUICKSTART.md / apps/api/README.md / apps/web/README.md / `docs/architecture/module-contribution-playbook.md`（`modules.enabled` → `modules.list`）全部改为 YAML 优先描述；`docscheck` playbook 断言同步。

### 测试

8. `config_test.go` `TestLoadResolvesProfileAndModuleOverrides` 重写：默认 mvp / list 覆盖（source=modules.list）/ preset 内置名（source=modules.preset）/ preset 自定义文件 / preset+list 互斥 / custom 无 modules fail closed / 旧 env 选择器被忽略（APP_PROFILE=demo 不再生效）。
