# E-002 · S3 P0：T-05 回收站时间 + T-01 顶栏用户下拉

## 事实

### T-05 · 回收站删除/恢复时间改 ISO-8601（D-006）

1. `apps/api/internal/handler/recyclebin.go` `recycleItemToMap`：`deletedAt` / `restoredAt` 由 `Unix()` 秒改为 UTC ISO-8601（`2006-01-02T15:04:05.000Z07:00`），与其它列表一致。存储层（`recyclebin/store`）仍为秒级列，仅 HTTP 投影变更。
2. `recyclebin_test.go` `TestRecycleBinListAndDetail` 新增断言：`deletedAt` 必须可被 `time.Parse` 解析。
3. 前端无需改动：`formatDisplayTime` 已只认 ISO 字符串。

### T-01 · 顶栏用户下拉（D-002）

4. `apps/web/src/app/App.tsx`：新增 `UserMenu` 组件 —— 单一触发器（头像圆标首字符 + 显示名 + 小箭头），全断点可见（移除 `hidden lg:flex` 横铺用户链与常驻退出按钮）。
5. 菜单项来自 `projection.user` 声明序（个人中心 → 我的钱包[如存在] → 设置）+ 分隔线 + 壳层注入的退出登录末项；钱包项缺席不阻塞（GOAL-022 挂上后自然出现）。
6. 外部点击 / Escape 关闭（与通知铃铛同模式）；`aria-haspopup/expanded`、`role=menu/menuitem`。
7. 移动端抽屉只保留业务导航（top + sidebar），不再重复用户链（D-002 §3）。
8. i18n：新增 `shell.userMenu`（en "User menu" / zh "用户菜单"）。
9. 新测试 `apps/web/src/app/user-menu.test.tsx`（4 例）：触发器与菜单序、导航后关闭、抽屉无用户链、Escape 关闭。

- 新 web 测试 5/5 通过（user-menu 4 + search-form-filters 1，后者属 T-02 但同批验证）。
