# D-002 · T-01 顶栏用户区下拉（S2 分项冻结）

## 背景

用户 2026-08-16 点名：个人中心 / 设置 / 退出登录应收进下拉，横铺在移动端不可用。I-005 为触发器与抽屉并存策略。用户在本轮 P-004 选择题中采纳推荐方案。

## 决定

1. **触发器**：头像圆标 + 显示名（`currentUser.name`，空则 `id`）+ 小箭头；全断点同一控件（不再 `hidden lg:flex` 横铺用户链）。
2. **菜单顺序**：个人中心 → 我的钱包（仅 `admin.wallet` 启用且该页已挂 `navigation.user` 时出现）→ 设置 → 分隔线 → 退出登录。条目来自 `projection.user` 声明序 + 壳层注入退出项。
3. **移动端**：汉堡抽屉只保留业务导航（`top` + `sidebar`），**不再**重复用户链。用户区只走顶栏下拉。
4. **不下沉**：语种切换、主题、通知铃铛仍留顶栏。
5. **退出**：菜单末项，无二次确认（与现按钮行为一致）。
6. **闭合 I-005**：上列即触发器与抽屉策略；状态 `verified`。

## 理由

- 与 Linear / Vercel / 常见 Admin 顶栏一致；小屏不再丢失个人中心/设置。
- 钱包项按模块显隐，避免未启用 wallet 时出现死链（T-04 负责挂 `navigation.user`）。
- 抽屉再放一份用户链会造成双入口、排序难与下拉对齐。

## 未选方案

- **仅头像触发**：更省宽，但本产品顶栏已有铃铛/主题，姓名有助于确认当前会话。
- **下拉 + 抽屉仍留用户链**：移动端双入口，退出仍只在下拉，心智不统一。

## 影响

- 实施面：`apps/web/src/app/App.tsx` 用户区；可复用通知铃的本地下拉模式（仓库尚无 DropdownMenu 原语）。
- 不改 Manifest 协议；不改 Profile 默认集。
- 「我的钱包」菜单项在 T-04 落地前可以缺席，不阻塞 T-01 实施。

## 后续
