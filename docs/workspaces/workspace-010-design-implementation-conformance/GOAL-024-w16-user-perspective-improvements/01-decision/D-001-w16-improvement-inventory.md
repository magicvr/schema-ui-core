# D-001 · W16 改进项台账（W16-F01～W16-F10）与边界界定

## 1. 背景与决策动因

在 2026-08-17 对 `apps/api` 与 `apps/web` 进行的真实用户全链路功能审视中，识别出一系列影响日常使用与企业落地的体验问题。经与 `workspace-011-admin-functional-modules`（标准 Admin 功能模块交付工作区）已有规划进行交叉比对：

- **排除项（由 workspace-011 规划承接）**：
  1. `B-10 组织 / 部门 / 岗位`（部门树与组织架构层级）
  2. `S-05 公告管理` / `B-09 消息模板`（管理员系统广播/公告下发）
  3. `B-09 邮件/短信配置`（SMTP/SMS 基础配置）
  4. `B-11 登录日志独立视图`（独立审计产品面）

- **纳入项（本工作区 workspace-010 W16 承接）**：
  属于基架已交付基础功能上的体验、易用性与交互断点修复，共 10 项（W16-F01～W16-F10）。

---

## 2. 改进项明细台账

### W16-F01 · 首次登录强制修改初始密码
- **问题现状**：种子账号 `admin / admin` 或管理员新建的用户账号拥有默认密码，首次登录直接进入后台，未强制改密，存在安全审计合规漏洞。
- **涉及模块**：`apps/api/internal/modules/authsession`、`apps/web/src/account`、`apps/web/src/app/LoginPage.tsx`
- **预期解法**：
  1. `users` 表增加 `must_change_password` 布尔字段（默认种子账号与新建账号为 `true`）。
  2. 登录响应包含该标记；前端 AuthContext 识别后进入强制改密拦截状态。
  3. 用户提交新密码成功后重置该标记，正式放行进入系统。

---

### W16-F02 · 文件库在线直接预览与一键复制直链
- **问题现状**：文件库上传的图片与文档无法在浏览器内直接预览，只能下载到本地；且缺少直接复制文件访问 URL 到剪贴板的按钮。
- **涉及模块**：`apps/api/internal/modules/filelibrary`、`apps/web/src/renderer`
- **预期解法**：
  1. 文件列表操作列增加“预览”：图片类型通过 Lightbox 模态放大预览，PDF/文本支持新标签页打开。
  2. 操作列增加“复制链接”：一键将文件下载/查看完整 URL 写入系统剪贴板并 Toast 提示。

---

### W16-F03 · 数据导入弹窗下载 CSV 示例模板与逐行错误定位反馈
- **问题现状**：导入模态框仅有文件上传控件，用户不知晓表头字段名称；导入校验失败时仅有全局错误提示，无法定位第几行哪个字段出错。
- **涉及模块**：`apps/api/internal/modules/datatransfer`、`apps/web/src/renderer`
- **预期解法**：
  1. 导入模态框表单内增加“下载 CSV 模板”超链接，提供合规示例文件。
  2. 导入接口返回 `fieldErrors` 数组（携带 `rowNumber`、`field`、`reason`），前端在模态框以表格或列表清晰呈现失败行明细。

---

### W16-F04 · 钱包余额金额“分转元”标准格式化展示与调账二次警示
- **问题现状**：底层存储与传输为最小货币单位（分），前端界面若直接展示整数（如 `10000`）容易引起金额歧义；调账输入负数或大额时缺乏警示防呆。
- **涉及模块**：`apps/api/internal/modules/wallet`、`apps/web/src/renderer`
- **预期解法**：
  1. 前端金额字段增加货币格式化通道（`format: currency` 或除以 100 并保留两位小数）。
  2. 调账与扣款模态框对大额数字与负数变动增加高亮警告提示与二次确认。

---

### W16-F05 · 定时任务 Cron 表达式自然语言解析与未来运行时间预览
- **问题现状**：非技术管理员配置 Cron 表达式（如 `0 0 2 * * ?`）容易误写，无即时语义反馈。
- **涉及模块**：`apps/web/src/renderer`（或 Cron 控件）
- **预期解法**：
  1. 在 Cron 输入框下方集成轻量 Cron 表达式自然语言解析引擎（中文人话描述，如“每天凌晨 02:00:00”）。
  2. 实时计算并列出未来 3 次预计运行时间。

---

### W16-F06 · 系统监控页面支持定时自动轮询刷新
- **问题现状**：监控页面加载后为静态快照，排查服务器性能波动时需手动反复刷新浏览器。
- **涉及模块**：`apps/web/src/renderer`（或系统监控 Schema/组件）
- **预期解法**：
  1. 监控页面顶部提供自动刷新下拉开关（`关闭 / 5秒 / 10秒 / 30秒`）。
  2. 开启后定时调用 API 无感静默更新指标卡片与状态。

---

### W16-F07 · 个人中心活跃会话支持“一键下线其他所有设备”
- **问题现状**：用户怀疑密码泄露或在公共设备登录过时，只能逐个会话点击吊销，缺乏全局一键自救能力。
- **涉及模块**：`apps/api/internal/modules/account`、`apps/web/src/account`
- **预期解法**：
  1. 后端提供 `POST /api/account/sessions/revoke-others` 接口，吊销除当前 Session ID 之外的所有活跃令牌。
  2. 个人中心会话管理卡片头部增加“下线其他设备”按钮与确认提示。

---

### W16-F08 · 登录算术验证码主动刷新 + MFA 密钥复制与恢复码 txt 下载
- **问题现状**：算术验证码用户想换题时必须刷新页面；MFA 绑定页面缺少快捷复制密钥和一键下载备份文件的按钮。
- **涉及模块**：`apps/web/src/app/LoginPage.tsx`、`apps/web/src/components/mfa-manager.tsx`
- **预期解法**：
  1. 登录页验证码右侧增加“换一题”图标按钮。
  2. MFA 绑定弹窗增加“复制密钥”按钮和“下载恢复码 (.txt)”按钮。

---

### W16-F09 · 数据字典项支持 Badge 颜色/标签风格配置
- **问题现状**：字典项仅能配置文字 Label，无法配置在表格中渲染时的色彩风格（如成功绿、错误红、告警黄）。
- **涉及模块**：`apps/api/internal/modules/datadictionary`、`apps/web/src/renderer`
- **预期解法**：
  1. 字典项实体与表单增加 `badgeStyle` / `tagColor` 可选字段（支持 `default`、`success`、`warning`、`destructive` 等预设）。
  2. 前端表格根据枚举字典项的样式属性自动渲染带色 Badge。

---

### W16-F10 · 系统设置支持页脚版权文字与备案号
- **问题现状**：企业自托管部署时，页面底部无法统一展示自定义公司版权和 ICP 备案号。
- **涉及模块**：`apps/api/internal/modules/settings`、`apps/web/src/app/App.tsx`
- **预期解法**：
  1. 系统通用设置增加 `copyrightText` 与 `icpNumber` 字段。
  2. 前端 Shell 在页面底部统一渲染页脚内容。

## 3. 规划与执行原则

1. **本阶段仅立项与规划落盘，暂不执行代码修改**。
2. 后续实施阶段按模块关联度推荐划分为 3 个整改子批次：
   - **批 A（安全与认证基线）**：W16-F01（首次改密）、W16-F07（一键下线其他）、W16-F08（验证码/MFA细节）
   - **批 B（核心资产与数据交互）**：W16-F02（文件预览复制）、W16-F03（导入模板/错误定位）、W16-F04（金额格式化/调账警示）
   - **批 C（系统运维与通用外观）**：W16-F05（Cron 解析）、W16-F06（监控自动刷新）、W16-F09（字典 Badge 样式）、W16-F10（页脚版权）
3. 待用户指令确认后，再行按批次建立子目标并实施。
