# GOAL-002 · R1 · 有界调研：候选池收集与三档分档

## 概述

本子目标是 Root 纲领路线图 **R1 阶段**（P-005 信息收集目标）：收集**业界通用 Admin 功能**与**常用业务领域**（订单 / 钱包为典型代表，类目 / 通知等入候选池），对照**已交付基架**（账号权限、Schema CRUD、Settings、多语种、设计系统、整份协议面 I-PROTO-FULL-001 → v2.8.0）区分「已覆盖」与「真·待建」，按 **一等公民 / 常用 / 增补** 三档分档，产出**分档清单**并**回写 Root 纲领路线图**（R2/R3/R4 细化）。

产出权威落在本目标附件与 Root 路线图；VP-011 正文不逐条改写（分层约定）。

## 当前边界

- 收集范围：业界通用 admin 能力（admin 框架/模板/SaaS 后台共性功能）+ 常用业务领域（订单、钱包、类目、通知；其他高频领域按证据纳入）。
- 对照基线：已交付模块（users / roles / settings / activity / operationlog 等）、既有页面集、协议面（v2.8.0 / I-PROTO-FULL-001 12/12 域）。
- **不**在此目标内实现任何功能；**不**私增协议语义；分档判定需有来源/证据（业界样本或基架对照）。
- 分档不改变 Profile 默认集 / 模块矩阵 / Manifest 装配 / 协议 pin / 共同门禁语义。
