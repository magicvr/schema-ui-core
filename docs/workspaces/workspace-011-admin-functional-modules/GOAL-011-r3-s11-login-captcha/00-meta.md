# GOAL-011-r3-s11-login-captcha · 登录验证码（防爆破补充）

## 概述

常用档 S-11（I-011-001 §4）：登录验证码——防爆破补充（基架已有失败自动锁定 423 + 限流）。在登录路径增加验证码挑战（图片/算术或 token 挑战），安全敏感目标。

## 当前边界

- 登录验证码：挑战生成 + 校验（集成 auth/login）+ 失败语义（与锁定/限流叠加）
- 开关与配置（默认行为、可关闭性需 S1 决策）
- 权限/审计与 admin 默认集

## 成功标准与路线图（P-001）

- [x] **S1 · 方案冻结**：挑战类型（算术/图形/token）、与锁定限流的叠加语义、配置开关、协议对照；方案级 self 审视（D-001/D-002/A-001，2026-08-14）
- [x] **S2 · 实现**：挑战端点 + 校验集成（auth/login）+ 配置 + 测试（E-002，2026-08-14）
- [x] **S3 · 验证**：单元/集成 + 登录链路实测 + 全量回归（go ./... 全绿、web 900/900，2026-08-14）
- [x] **S4 · go 影响判定 + 自审**（A-002 pass：未启用字节级不变；2026-08-14）
